# MegaBite – Restaurant Management & Sales Forecasting System

## Overview

MegaBite is a restaurant management system developed as part of my Final Year Project. It aims to help restaurant owners manage inventory, monitor sales, and make better inventory replenishment decisions through machine learning-based sales forecasting.

## Key Features

- Inventory management and stock monitoring.
- Menu and order management.
- Sales monitoring and analysis.
- Machine learning-based sales forecasting using XGBoost.
- Inventory replenishment recommendations.

## Technologies Used

- **Programming:** Python, JavaScript, HTML, CSS
- **Machine Learning:** XGBoost
- **Database:** Firebase

## Project Status

Currently under development as a Final Year Project.
